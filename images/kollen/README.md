# Kollen's photos

Every photo in this folder was taken by Kollen (creator of Fly Easy). The
`kollen-` prefix marks a photo as his; stock photos live one level up in
`images/`. Files here are web copies (max 1600px, ~74% JPEG) with camera,
date and location metadata stripped. Full-size originals live in
`_originals/` (git-ignored).
